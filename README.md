# Halliday SDK Wagmi Rainbowkit Example

Run the Halliday SDK widget using a Wagmi Rainbowkit provider initialized on the page before opening the widget.

### How to Run

Get a [Reown project ID](https://reown.com/) (formerly WalletConnect).

Get a free [Halliday API key](https://dashboard.halliday.xyz) now.

Create a `.env` file in the project root with your API keys:

```
VITE_WALLETCONNECT_PROJECT_ID=your_reown_project_id
VITE_HALLIDAY_API_KEY=your_halliday_api_key
```

Install dependencies:

```bash
npm install
```

Run:

```bash
npm run dev
```
